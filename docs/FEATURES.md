# AntiDrive Feature Matrix

| Feature | Description | Target Audience |
|---------|-------------|-----------------|
| **Authentication** | Secure email and password authentication, password resets. | All Users |
| **Row Level Security** | Postgres-level enforcement ensuring absolute data isolation between tenants. | Security / Infra |
| **Secure Storage** | Private Supabase buckets preventing unauthorized direct URL access. | Security / Infra |
| **Student Dashboard** | Central hub for users to view their files and quick stats. | Students / Users |
| **Workspace Management** | Multi-level folder hierarchies, file moving, renaming, and organization. | All Users |
| **File Uploads** | Drag-and-drop React interface capable of securely uploading large files. | All Users |
| **Instructor Dashboard** | Elevated interface for admins to manage all users and global settings. | Admins |
| **Activity Analytics** | Global activity logging tracking file modifications, logins, and deletions. | Admins |
| **Grade Management** | Secure CSV bulk import system allowing admins to distribute grades privately. | Admins |
| **AI Quiz Generation** | Context-aware AI integration (Gemini) capable of turning study notes into quizzes. | Students / Users |
